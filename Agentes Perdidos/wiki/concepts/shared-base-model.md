The [[second-brain]] agent builds a per-project LLM-wiki (the Karpathy [[llm-wiki-pattern]]) **inside that project's Obsidian vault**. Generic, non-confidential knowledge that is identical across every project is kept **once** in the shared base and *linked* by each project brain instead of being re-ingested — saving tokens and giving one source of truth.

## Where things live
- **Project-specific facts** → that project's own vault brain (this folder, `Agentes Perdidos/`, for the repo itself).
- **Generic knowledge** → the shared base at `agents/second-brain/shared/` (git-tracked in this public repo). A project brain references shared pages **by path**; links are one-way (project → shared), never shared → project.
- **Confidential facts** → only the relevant project's own brain. Never copied to the shared base or any cross-project artifact. (This repo's brain is non-confidential.)

## Shared base pages (link these, don't duplicate)
Path prefix `agents/second-brain/shared/wiki/`:
- `overview/agentes-perdidos-agents.md` — the agents catalog.
- `concepts/llm-wiki-pattern.md` — the [[llm-wiki-pattern]] itself.
- `concepts/uv-pep723-pattern.md` — the [[uv]] / PEP-723 run pattern.
- `concepts/claude-code-context-management.md` and `sources/claude-code-best-practices.md` — Claude Code practices.
- `sources/karpathy-llm-wiki.md` — origin source.

## Helper script
`agents/second-brain/secondbrain.py` (stdlib only): `detect`, `init`, `log`, `reindex`, `search`, `stats`. Don't hand-edit `index.md` — it's regenerated by `reindex` from each page's frontmatter first line.
