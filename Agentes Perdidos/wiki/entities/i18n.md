Internationalizes **any** project end-to-end (frontend + backend). Scans for user-facing strings, extracts them into translation files with semantic dotted keys, authors the two mandatory base languages by AI, then auto-generates ~190 more keylessly.

## How it works
- **Two base languages always AI-authored and sacred**: **pt-BR** and **en** — the source of truth. Never overwritten by machine output.
- **~190 other languages** generated mechanically by `translate.py` via a free keyless Google-translate script (**zero LLM tokens**); each carries a machine-generated header and is safe to regenerate.
- **Language switcher** wired into settings AND every pre-auth surface (landing/login/signup) so foreign visitors aren't stranded before login.
- **Completeness guarantee**: a code↔base audit so no key ever renders as raw text on screen.
- **Format adapters**: i18next JSON (React / React-Native) or `.properties` (Java/Spring/custom-React). `merge_keys.py` (appends agent-extracted keys into the pt-BR/en base files, idempotent) now auto-detects the base format and supports **both**: flat `.properties` and nested i18next JSON (dotted keys nested via the same flatten/unflatten model as `translate.py`).
- **Incremental re-runs** pick up only what changed. Launches sub-agents for big projects.

## Lost-agent state
Persists tasklist/keymap/progress/coverage in the *target* project's brain (existing wiki dir, else `./.i18n/`) — see [[lost-agent-rule]].
