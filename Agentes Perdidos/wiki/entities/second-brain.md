Builds and maintains a persistent **LLM-wiki "second brain"** for any project — the Karpathy [[llm-wiki-pattern]], productized. Instead of re-deriving answers from raw files on every query (RAG), it compiles knowledge **once** into an interlinked markdown wiki that lives **inside the project's Obsidian vault** and keeps it current. **This page documents the agent that built this very brain.**

## Where the brain lives
Inside the folder that contains `.obsidian/` (for this repo: `Agentes Perdidos/`). Detection order via `detect`: one vault → that's it; multiple → ask; none → fall back to `./.second-brain/`. Never stored in `agentes_perdidos` itself — only the agent + the [[shared-base-model|shared base]] live in the repo.

## Layout (inside the vault)
`CLAUDE.md` (per-project schema), `index.md` (catalog, regenerated by reindex — don't hand-edit), `log.md` (append-only history), `raw/` (immutable sources), `wiki/{overview,entities,concepts,comparisons,decisions,sources}/`. Every page opens with YAML frontmatter (title/type/created/updated/sources/tags) and cross-links with `[[wikilinks]]`. Contradictions are flagged inline, never silently overwritten.

## Operations
- **onboard** `<project>` — detect vault, init, broad initial ingest of the project itself, reindex + log.
- **ingest** `<source>` — read, summarize to `wiki/sources/`, update touched pages, flag contradictions.
- **query** `<question>` — search + index, synthesize with `[[citations]]`, file the answer back.
- **lint** — health-check via `stats` (orphans, stale claims, missing cross-refs, drift).

## Key files
- `agents/second-brain/SKILL.md` — brain.
- `agents/second-brain/secondbrain.py` — stdlib helper: `detect | init | log | reindex | search | stats`.
- `agents/second-brain/shared/` — the generic [[shared-base-model|shared base]] linked by every project brain.
