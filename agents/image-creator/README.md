# image-creator

Smart image/video-generation agent. Picks the best of three APIs per asset, with automatic
fallback if a provider has no key or credit:

- **Transparent** (logos, mascots, icons, sprites, UI frames) → **OpenAI `gpt-image-1.5`** (only one with alpha)
- **Normal / photographic** (backgrounds, hero art, banners) → **Gemini `gemini-2.5-flash-image`** ("Nano Banana"), falling back to OpenAI → Kling
- **Video** (animate a still, text-to-video) → **Kling AI**

Every run logs an estimated cost; `imagegen.py usage` shows today / 7-day / all-time spend.

The full decision logic lives in [`SKILL.md`](SKILL.md). The hands are [`imagegen.py`](imagegen.py).

## Setup

1. Copy the repo's `.env.example` to `.env` and fill the keys you have: `OPENAI_API_KEY`,
   `GEMINI_API_KEY`, and optionally `KLING_ACCESS_KEY` + `KLING_SECRET_KEY`. Missing keys are
   skipped automatically by the fallback chain.
2. Have [`uv`](https://docs.astral.sh/uv/) installed. Deps auto-install on first run (PEP-723 inline metadata).

## Use it as an agent

Open a Claude Code (or other LLM) session in **another project** and give it:

> Read `<repo>/agents/image-creator/SKILL.md` and this project's `prompts.md`.
> Create all the missing image assets and save them to their expected paths.

The agent reads the style guide, routes each asset, runs `imagegen.py`, and drops files
at the correct paths/extensions.

## Use it directly (CLI)

```bash
# transparent logo
uv run imagegen.py generate --prompt "a CaipiRAG wordmark logo, transparent" \
  --out ./logo.png --transparent --aspect 1:1

# opaque hero background
uv run imagegen.py generate --prompt "fantasy Brazilian sertão at golden hour" \
  --out ./hero.jpg --opaque --aspect 16:9

# edit an existing image
uv run imagegen.py generate --prompt "raise the arm in a wave" \
  --ref ./mascote.png --out ./mascote-aceno.png --opaque

# animate a still into a video (Kling)
uv run imagegen.py video --prompt "gentle wind, camera pushes in" \
  --ref ./hero.png --out ./hero.mp4 --duration 5

# spending so far
uv run imagegen.py usage
```

`uv run imagegen.py generate --help` (or `video --help`) for all flags.

## Notes

- OpenAI image endpoints require org verification. Gemini outputs carry an invisible SynthID watermark.
- Kling needs a prepaid resource pack; a `429` means no active credit (auth is fine). Video is billed by the second.
- `.svg` can't be generated by any API — the agent produces a transparent raster and flags it for tracing.
- Model names are pinned in `imagegen.py` and overridable via `.env` (`OPENAI_IMAGE_MODEL*`, `GEMINI_IMAGE_MODEL`, `KLING_*_MODEL`).
- Estimated costs are logged to `.usage/ledger.jsonl` (gitignored).
